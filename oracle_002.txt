1.DQL (Data Query Language, 데이터 질의어)

정의: 데이터베이스에 저장된 데이터를 검색하고 조회하는 데 사용됩니다. (넓은 의미에서는 DML의 일부로 보기도 합니다.)

대표 명령어: SELECT


2.DML (Data Manipulation Language, 데이터 조작어)

정의: 테이블 안에 있는 실제 데이터(행, 레코드)를 추가, 수정, 삭제하는 등 조작할 때 사용됩니다.

대표 명령어: INSERT, UPDATE, DELETE


3.DDL (Data Definition Language, 데이터 정의어)

정의: 테이블, 인덱스, 뷰 등 데이터베이스 객체 자체의 구조를 생성, 변경, 삭제합니다.

대표 명령어: CREATE, ALTER, DROP
