1. HTML, CSS, JS의 개념과 역할

HTML (HyperText Markup Language)
개념: 웹 페이지의 뼈대와 구조를 잡는 마크업 언어입니다.

역할: 텍스트, 이미지, 링크, 버튼 등 웹 화면에 들어갈 '내용물'을 정의합니다.


CSS (Cascading Style Sheets)
개념: HTML로 만들어진 뼈대를 시각적으로 꾸며주는 스타일 시트 언어입니다.

역할: 색상, 폰트, 크기, 여백, 배경 등을 설정하여 웹 페이지의 디자인을 완성합니다.


JS (JavaScript)
개념: 웹 페이지에 생명력을 불어넣는 프로그래밍 언어입니다.

역할: 정적인 웹 페이지를 동적으로 만듭니다. 팝업창 띄우기, 버튼 클릭 시 동작, 애니메이션, 서버와 데이터 주고받기 등을 처리합니다.
